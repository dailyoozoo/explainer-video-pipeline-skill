# “不写代码的PM”新闻风格

本用户已确认的展示偏好；其他账号按用户要求适配。参数是起点，手机可读性与最新指令优先。

默认1080×1920、30fps。摄影背景贯穿全屏，渐变保障文字清晰。顶部章节标题在同章子镜头间稳定，下面保留简洁介绍；素材、图表和字幕共用字体、颜色、对齐线。避免独立黑栏、重复大标题和装饰英文。

1080宽可从左右72px、标题84px、介绍34–38px、字幕52px起调。字幕底边距245px是近期短片起点，平台安全区另行实测。按真实字体像素检查宽度；太长先按语义重分，不能无限缩字。

| 元素 | 默认处理 |
|---|---|
| 章节标题、内容介绍 | 保留，不重复整句口播 |
| 每页重复日期 | 去掉 |
| 事件日期、评测快照日期 | 有助解释时保留 |
| 字幕 | 仅一处单行，跟随口播，可跨镜头 |
| 数据单位、配置、观点主体和必要限定 | 贴近相关数据或观点保留 |
| “能力示意/释义”“数据·…”等制作标签 | 记在制作文档，成片不显示 |
| 音乐作者、许可、完整URL | 放来源文档与发布简介，满足许可要求 |

字幕源放 `output/subtitles/`，不要与同名MP4并排，避免播放器在烘焙字幕上重复加载SRT。

## 证据与图表

截图等比适配，相关正文、账号身份与上下文可见。不要强裁为同一高度；长材料分镜或选取相关段落。手机读不清的图表按留存数据重绘并记录性质，不能伪装成官网截图。

近期图表可参考浅色面板 `#f2f5ef`、墨绿字 `#173031`、青柠强调 `#b6e65d` 和灰绿次要条形。比较用同一零基线和比例；单位、配置、日期、样本范围清晰。不同配置的榜单称“前五个配置”，不能偷换成“前五款模型”。单价下降与评测任务成本上升可以同时成立。

条形短暂单调展开后稳定阅读是有效方案，最近案例约0.77秒展开，但不是硬性时长。数字动效应留稳定读数阶段，数据与来源文件哈希一同保存。

## 镜头与关注页

按信息变化、语句节奏和阅读需要切镜。周报曾有用户明确要求每镜不超过两秒，这只属于那条片；长证据和图表需要阅读时间。同背景可延续，纯缩放同图或换字幕不算新的信息镜头。

片尾用用户提供的原始关注页，保留头像、名称、按钮与简介，不叠重复账号、字幕、音乐作者或制作信息；留足阅读和配乐淡出时间。缺失时定位正确资产，本仓库不含私人账号图片，不生成冒充原图的替代头像。
