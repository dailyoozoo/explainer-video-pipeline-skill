# Repository maintenance

This is a portable video-production skill. Keep `SKILL.md` concise and procedures in linked references. Maintain real, documented CLI contracts.

- Preserve actual authorization; avoid repeated approvals and mandatory dependencies on particular providers, accounts or external skills.
- Treat models, API fields, prices, quotas, rights and news facts as historical unless verified for the current task.
- Never publish credentials, private configuration, local absolute paths or third-party raw media.
- Preserve continuous narration, input fingerprints and versioned outputs. Do not infer speech boundaries from silence alone.
- Technical checks, extracted frames, actual visual review, playback and human listening are distinct evidence.
- Validate changed scripts using a short synthetic render outside the working tree and meaningful negative checks. Do not call paid TTS or regenerate real videos for maintenance.
- Check reference links, example JSON and skill frontmatter before publishing.
